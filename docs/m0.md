# M0 smoke sequence

Deterministic Soft script `soft/go/m0_smoke.aura`. No RNG. Black is `1`,
white is `2`, empty is `0`. Coordinates are `(x,y)` with `y` increasing
downward in `go:print-board`.

Dialect: **japanese-simple-ko-9x9**.

## What is legal

1. `(go:reset!)` — empty 9×9, Black to play, ko clear, capture counters 0.
2. `(go:place! color x y)` — succeeds only when `color` is the side to play,
   the point is empty and on-board, the point is not the active ko ban, and
   the mover's group has at least one liberty after captures. Returns `1`
   or `0`. A failure does not change the board or the side to play.
3. Captures: every orthogonal opponent group with zero liberties is removed.
   `*last-caps*` is the number of stones removed by the successful move.
4. Simple ko is set only when all three hold:
   - `*last-caps*` is 1
   - the capturer's group size is 1
   - that group has exactly one liberty
   The ko point is the captured stone. `*ko-color*` is the opponent, who
   may not play there next. A capture of two or more stones does not set ko.
   A single-stone capture whose capturer has two or more liberties does not
   set ko (the corner case in the smoke).
5. `(go:pass!)` clears ko, adds one to `*passes*`, and flips the side to play.
6. `(go:empty-count)` counts empty points. It is not a score.

Not in M0: superko, komi, territory, eyes, seki, handicap, snapback as a
named test (the rule allows it, because a capturer group larger than one
stone does not set ko), and any `fiber_live` stamp.

## Scripted evidence

1. **Open capture.** `B(1,0) W(0,0) B(0,1)` captures the corner white.
   `OPEN_CAPS=1`, `KO_AFTER_OPEN=0` (the capturer is not in atari).
2. **Ko.** Build:
   ```
   B W . W
   . B W .
   ```
   with fillers `B(4,4)` and, before the capture, `W(2,1)`.
   `(go:liberties 1 0)` is 1. `B(2,0)` captures. `CAPTURE=1`, `KO=2`
   (white banned), `KO_X=1`, `KO_Y=0`. The board print starts
   `B.BW.....`. `W(1,0)` returns 0 (`KO_BLOCK=0`). `W(5,5)` clears the ban.
   Black passes. `W(1,0)` recaptures (`RECAP_CAPS=1`). Running totals
   `CAPS_BLACK=1` `CAPS_WHITE=1`.
3. **Multi capture.** `B(2,0) W(0,0) B(0,1) W(1,0) B(1,1)` removes two
   whites. `MULTI=2`, `KO_AFTER_MULTI=0`.
4. **Suicide.** `B(1,0) W(8,8) B(0,1)`, then `W(0,0)` returns 0 and `(0,0)`
   stays empty. White is still to play, then passes. `EMPTY=78`
   (three stones on the board).
5. If every `expect` matched, the script prints `GO_M0_OK`. Otherwise
   `GO_M0_FAIL`.

`scripts/smoke_soft.sh` runs that file inside
`ghcr.io/cybrid-systems/dev:v1.0.9` and exits non-zero unless the evidence
lines and `GO_M0_OK` are present.

## Limits to remember

- Ko is "cannot repeat the last position by an immediate single-stone
  recapture", checked locally (group size 1 and one liberty), not by
  hashing the whole history. A long cycle is legal in M0.
- The side to play is enforced. The smoke never plays two blacks in a row.
- Pass does not end the game. Two passes are visible only as `*passes* = 2`
  if you call pass twice without a play in between (the smoke passes once
  per phase, and a play resets the counter).
